Reactの state って何？

「画面を変化させるための記憶」

  • 値を覚えておく
  • 値が変わると React が再描画する
2 / 10

小さな例：いいねボタン

const [liked, setLiked] = useState(false)

<button onClick={() => setLiked(!liked)}>
  {liked ? "♥ いいね済み" : "♡ いいね"}
</button>

たった1つのボタンでも、UIの状態が変わる。

3 / 10

「普通の変数」ではダメ？

let liked = false

liked = true

値は変わる。でも React はそれを知らない。

UIを更新する必要があるなら、state が候補。
